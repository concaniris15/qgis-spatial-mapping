# qgis-spatial-mapping

A spatial geographic data visualization and vector layer mapping project created using QGIS.

---

## 🗺️ Open Project in QGIS
Para mabuksan at ma-inspect ang mismong source project sa **QGIS App**:

1. **Download Project File:** [📥 Download QGIS Project File](./your_project_name.qgz)
2. **Open in App:** I-double click ang na-download na `.qgz` file para kusa itong bumukas sa iyong **QGIS Desktop Application**.
